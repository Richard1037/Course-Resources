# C语言核心知识清单

> 本清单按「知识点 + 普遍规律」组织，聚焦概念本质与通用规则，而非逐题解答。

---

## 一、程序的基本结构

### 1.1 main 函数
- `main` 是程序的**入口函数**，程序从 `main` 开始执行。
- `main` **不要求**写在文件最前面，可放在任意位置；只要被调用前已有声明即可。编译器最终都会从 `main` 开始执行。

### 1.2 语句书写
- C 语言以 **分号 `;`** 作为语句结束标志，**不以换行**为界。
- **一行可以写多条语句**，用 `;` 分隔。
- **一条语句可以写在多行**（长语句允许换行）。

### 1.3 输入输出机制
- **C 语言本身没有输入输出语句**，不提供输入输出关键字。
- 输入输出靠调用**标准库函数**实现：
  - 输出：`printf()`
  - 输入：`scanf()`
  - 使用前须包含头文件 `#include <stdio.h>`

### 1.4 注释
- 注释是给程序员看的说明文字，**不参与编译**。
- 编译器在**预处理阶段**会删除所有注释，因此注释中的任何拼写错误**不会被检查**。

## 二、常量（字面量）

### 2.1 整型常量：三种进制

| 进制   | 前缀           | 允许的字符           | 示例            |
| ------ | -------------- | -------------------- | --------------- |
| 十进制 | 无前缀         | 0~9                  | `160`, `-123`   |
| 八进制 | `0`            | 0~7                  | `0123`, `0010`  |
| 十六进制 | `0x` 或 `0X` | 0~9 和 a~f / A~F     | `0xff`, `0X1A`  |

**普遍规则**：
- 进制由**前缀**决定，前缀本身不计入数值。
- **八进制**中一旦出现 `8` 或 `9` 即非法（如 `0986`）。
- **十六进制**大小写字母等价（`0xff` == `0xFF`）。
- 负号 `-` 不属于进制表示，可直接作用于各进制数（如 `-0x11`、`-017`）。
- 前导零不影响数值（八进制中 `0010` 仍是八进制数）。

### 2.2 浮点型常量：两种形式

**（1）小数形式** —— 必须含小数点 `.`，如 `3.14`、`.5`、`3.`、`0.0`。

**（2）指数形式（科学计数法）** —— 形如 `尾数 E/e 指数`。

**普遍规则**：
- `e` 或 `E` **之前必须有数字**（尾数），之后**必须为整数指数**。
- 指数不能是小数（`2e4.2` 非法）。
- `e` 前后不能有空格。

> 注：`123e3` 是合法浮点常量（= 123000）；它表示的是浮点数，而不是整型常量。

### 2.3 字符常量
- 用**单引号**括起来的**一个**字符，如 `'A'`、`'5'`、`' '`、`'\n'`。
- **转义字符视作一个字符**。
- 单引号内不能为空（`''` 非法），也不能放多个普通字符（`'ab'` 非法）。

### 2.4 字符串常量
- 用**双引号**括起来的**零个或多个字符**组成的序列，如 `"Hi"`。
- **区分**：`'A'` 是字符常量，`"A"` 是字符串常量，二者本质不同。

### 2.5 转义字符
- 以反斜杠 `\` 开头的特殊字符，用于表示无法直接书写的控制字符或特殊符号。

| 转义字符 | 含义           | ASCII |
| -------- | -------------- | ----- |
| `\n`     | 换行           | 10    |
| `\t`     | 制表（Tab）    | 9     |
| `\0`     | 空字符（串结束符） | 0  |
| `\\`     | 反斜杠本身     | 92    |
| `\'`     | 单引号         | 39    |
| `\"`     | 双引号         | 34    |
| `\r`     | 回车           | 13    |
| `\b`     | 退格           | 8     |

**数字转义**：
- 八进制转义：`\ddd`（1~3 位八进制数字），如 `'\101'` 表示 ASCII 码 65 的 `'A'`。
- 十六进制转义：`\xhh`（十六进制数字），如 `'\x41'` 表示 `'A'`。

## 三、变量与数据类型

### 3.1 基本数据类型（字节数取决于平台，下表为常见实现）

| 类型     | 关键字            | 字节数 | 取值范围（常见）                     |
| -------- | ----------------- | ------ | ------------------------------------ |
| 字符型   | `char`            | 1      | 0~255（作为字节存储）                 |
| 整型     | `int`             | 4      | -2147483648 ~ 2147483647             |
| 短整型   | `short`           | 2      | -32768 ~ 32767                       |
| 长整型   | `long`            | 4/8    | 因平台而异                           |
| 单精度   | `float`           | 4      | 约 ±3.4×10³⁸                         |
| 双精度   | `double`          | 8      | 约 ±1.7×10³⁰⁸                        |

**符号修饰**：
- 每种整型可用 `signed` / `unsigned` 修饰，决定是否有符号位。
- `short int` 占用 16 位，无符号范围 `0 ~ 65535`，有符号范围 `-32768 ~ 32767`。
- **普遍规律**：`unsigned` 类型二进制最高位也用于表示数值，因此正数范围翻倍，但不能表示负数。

### 3.2 变量声明与赋值
- 变量必须先**声明**再使用；未声明的变量会导致编译错误。
- 声明语句可一次声明多个变量：`int a, b, c;`。
- 声明时可同时初始化：`int x = 12;`。

### 3.3 类型匹配与赋值转换
- **小类型赋给大类型**：自动转换（安全，一般不丢数据）。
- **大类型赋给小类型**：可能截断/溢出，需谨慎。
- **浮点数赋给整型**：截断小数部分（不四舍五入）。
- 赋值要求两侧类型**兼容**；赋值号左边必须是可以被赋值的**左值**（即变量），不能是表达式。

## 四、运算符

### 4.1 算术运算符
| 运算符 | 含义   | 说明                     |
| ------ | ------ | ------------------------ |
| `+`    | 加     |                          |
| `-`    | 减     |                          |
| `*`    | 乘     |                          |
| `/`    | 除     | 整数相除结果仍为整数     |
| `%`    | 取模   | **只能用于整数**         |

**整数除法规律**：两个整数相除，结果取**整数部分**（向零取整，不四舍五入）。
```c
3 / 2   // 1，不是 1.5
14 / 3  // 4，不是 4.666...
```

**取模规律**：结果为**余数**，符号与被除数相同；操作数必须是整数，浮点数对 `%` 非法。
```c
13 % 10  // 3
-7 % 3   // -1（符号跟随被除数 -7）
```

### 4.2 关系与逻辑运算符
| 类别 | 运算符                          |
| ---- | ------------------------------- |
| 关系 | `<`、`<=`、`>`、`>=`、`==`、`!=` |
| 逻辑 | `&&`（与）、`||`（或）、`!`（非） |

- 关系/逻辑运算的结果是 `0`（假）或 `1`（真）。

### 4.3 赋值与复合赋值
赋值运算符 `=` 把右边表达式的值赋给左边变量。

**复合赋值**是把「算术运算 + 赋值」合并的简写，含义如下：

| 复合赋值 | 等价展开       |
| -------- | -------------- |
| `a += b` | `a = a + b`    |
| `a -= b` | `a = a - b`    |
| `a *= b` | `a = a * b`    |
| `a /= b` | `a = a / b`    |
| `a %= b` | `a = a % b`    |

**关键规律**：`a op= expr` 会**先完整计算整个右侧表达式 `expr`**，再把 `a` 与结果做 `op` 运算，最后赋值给 `a`。
```c
int n = 0;
n += (n = 10);   // 先执行 (n=10) 使 n=10，再 n = n + 10 = 20
```

### 4.4 自增自减运算符
| 运算符 | 名称       | 行为规律                   |
| ------ | ---------- | -------------------------- |
| `++i`  | 前置自增   | **先加 1，再使用新值**     |
| `i++`  | 后置自增   | **先用原值，再加 1**       |
| `--i`  | 前置自减   | **先减 1，再使用新值**     |
| `i--`  | 后置自减   | **先用原值，再减 1**       |

**普遍规律**：前置形式返回值是「变化后的值」，后置形式返回值是「变化前的原值」；但无论前置后置，变量最终都会变化。
```c
int a = 5, b;
b = ++a;   // a=6, b=6
b = a++;   // b=6（原值）, a=7
```

### 4.5 运算符优先级与结合性（核心）

**优先级从高到低**（常用部分）：

| 优先级 | 运算符                        | 结合性 |
| ------ | ----------------------------- | ------ |
| 最高   | `()` 括号                     | 左到右 |
| ↑      | `++` `--` `-`(负) `(类型)`  | 右到左 |
|        | `*` `/` `%`                   | 左到右 |
|        | `+` `-`                       | 左到右 |
|        | `<` `<=` `>` `>=`             | 左到右 |
|        | `==` `!=`                     | 左到右 |
|        | `&&`                          | 左到右 |
|        | `\|\|`                        | 左到右 |
| 最低   | `=` `+=` `-=` 等赋值          | 右到左 |

**两条普遍规律**：
1. **先按优先级从高到低计算**，同一优先级按结合性方向计算。
2. 括号 `()` 优先级最高，永远是改变求值顺序最可靠的手段。

```c
2 + 3 / 2        // 先算 3/2=1，再 2+1=3
16 - 13 % 10     // 先算 13%10=3，再 16-3=13
```

## 五、表达式求值规则

### 5.1 赋值表达式的值
- **赋值表达式本身也有值**，其值等于**赋值后变量所获得的值**。
```c
int a;
int b = (a = 10);   // (a=10) 表达式的值为 10，故 b=10
```

**嵌套赋值**：从最内层括号开始、按赋值运算符结合性（右到左）依次求值。
```c
int x, y, z;
x = (y = (z = 10) + 5) - 5;
// z=10 → y=15 → x=10
```

### 5.2 隐式类型转换（自动类型提升）
当表达式含不同类型操作数时，**低精度类型自动转换为高精度类型**再运算。

转换等级（由低到高）：
```
char/short → int → unsigned int → long → float → double
```

**普遍规则**：
- `float` 与 `double` 运算 → `float` 转 `double`。
- `int` 与 `float`/`double` 运算 → `int` 转 `float`/`double`。
- `char`/`short` 参与运算 → 一律先提升为 `int`。
- 整个表达式的结果类型，是其中**最高等级**的类型。

```c
// 10 + 'a' + i*f   (i 为 double, f 为 float)
// 'a'→int, f→double, 最终结果为 double
```

### 5.3 强制类型转换（显式转换）
- 语法：`(目标类型) 表达式`，如 `(float)2`。
- 作用：把表达式结果**显式**转换为指定类型。
- 常用于：让整数除法变成浮点除法。

```c
2 / 3          // 0（整数除法）
(float)2 / 3   // 0.666...（强制转 float 后再除）
```

## 六、数据的底层表示

### 6.1 补码（有符号整数）
计算机中**有符号整数用补码**表示：
- **正数**：补码 = 本身。
- **负数**：补码 = 原码按位取反（反码）再加 1。
- **最高位为符号位**：0 表示正，1 表示负。

负数的补码求法：
```c
-12345（16 位）
12345 原码 = 0011 0000 0011 1001
取反      = 1100 1111 1100 0110
加 1      = 1100 1111 1100 0111   // -12345 的补码
```

### 6.2 有符号数与无符号数的转换
**核心规律：转换时二进制位模式完全不变，只是「解释方式」改变。**

- **有符号 → 无符号**：若原值为负，等于 `原值 + 2^n`（n 为位数）。
  - 16 位：`-12345 → 53191`（即 `-12345 + 65536`）。
- **无符号 → 有符号**：若超出有符号正数上限，等于 `原值 - 2^n`。
  - 32 位：`4294967295 → -1`（即 `4294967295 - 4294967296`）。

**溢出规律**：`unsigned` 值一旦超过该位宽的有符号最大正数（如 32 位的 `2147483647`），转换回 `int` 便会得到负数。

### 6.3 字符编码（ASCII）
- 字符在内存中以 **ASCII 码（整数）** 存储，因此**字符可参与算术运算**。

**ASCII 连续规律**：
| 区间      | 值域    | 规律     |
| --------- | ------- | -------- |
| `'0'`~`'9'` | 48~57   | 连续     |
| `'A'`~`'Z'` | 65~90   | 连续     |
| `'a'`~`'z'` | 97~122  | 连续     |

**关键关系**：同一字母小写比大写大 **32**（`'a' - 'A' == 32`）。

字符运算的常用变换：
```c
'5' - '0'     // 5（数字字符→数值）
7 + '0'       // '7'（数值→数字字符）
'b' - 32      // 'B'（小写→大写）
'B' + 32      // 'b'（大写→小写）
```

**字符加减规律**：先按 ASCII 码转成整数运算，结果再按需解释为整数或字符。
```c
c2 = 'A' + '6' - '3';   // 65 + 54 - 51 = 68 → 字符 'D'
```

### 6.4 IEEE 754 浮点数表示
浮点数按 **IEEE 754 标准**分三部分存储：

**单精度（float，32 位）**：1 位符号 + 8 位指数 + 23 位尾数。
**双精度（double，64 位）**：1 位符号 + 11 位指数 + 52 位尾数。

| 部分     | 含义                   | 说明                       |
| -------- | ---------------------- | -------------------------- |
| 符号位 S | 0=正，1=负             | 决定符号                   |
| 指数位 E | 实际指数 + 偏移量      | 单精度偏移 127，双精度 1023 |
| 尾数位 M | 有效数字的小数部分     | **隐含整数部分 1**         |

**十进制 → 单精度转换步骤**：
1. 绝对值转二进制（整数部分除 2 取余，小数部分乘 2 取整）。
2. 规范化成形如 `1.xxx × 2^n` 的科学计数法。
3. 取符号位、指数位（n + 127）、尾数位（去掉隐含的 1）。
4. 拼成 32 位二进制，再转十六进制。

**示例 `-12.5`**：
```
12.5 = 1100.1₂ = 1.1001₂ × 2³
符号 = 1（负）
指数 = 3 + 127 = 130 = 10000010₂
尾数 = 1001（其余位补 0 至 23 位）
结果 = 1 10000010 10010000000000000000000
十六进制 = 0xC1480000
```

## 七、格式化输出 printf

### 7.1 常用格式说明符

| 格式符 | 用途                               |
| ------ | ---------------------------------- |
| `%d`   | 有符号十进制整数                   |
| `%u`   | 无符号十进制整数                   |
| `%f`   | 浮点数（默认 6 位小数）            |
| `%c`   | 单个字符                           |
| `%s`   | 字符串                             |
| `%x`   | 十六进制（小写），`%X` 为大写      |
| `%o`   | 八进制                             |
| `%e`   | 科学计数法                         |

### 7.2 宽度与精度：`%m.nf`
- **`m`**：最小总宽度（含小数点），不足时右对齐补空格。
- **`n`**：小数点后位数（四舍五入）。
```c
printf("%4.2f", 8.00);  // 输出 " 8.00"（前导一个空格补足 4 位）
printf("%.2f", 8.00);   // 输出 "8.00"
```

### 7.3 `%d` 与 `%c` 的本质区别
- 同一整数既可用 `%d` 按「数值」输出，也可用 `%c` 按「字符」输出。
```c
char ch = 65;
printf("%d", ch);   // 65
printf("%c", ch);   // A
```

## 附：易错点速查

### 常量
- 八进制以 `0` 开头、只用 0~7；出现 8/9 即非法。
- 十六进制以 `0x`/`0X` 开头；`0abc` 缺 `x` 不是十六进制。
- 指数形式 `e/E` 后必须是整数；`2e4.2` 非法。
- 字符常量用单引号、字符串用双引号。
- 转义字符必须以 `\` 开头。

### 运算
- 整数除法结果取整：`3/2 == 1`。
- `%` 只能用于整数，浮点数不能用。
- 后置 `++/--` 返回原值，前置返回新值。
- 复合赋值先算完右侧整个表达式。
- 赋值表达式本身有值（等于赋值后的值）。

### 类型
- 隐式转换遵循 `char → int → float → double` 提升方向。
- 有/无符号转换：位模式不变，只改变解释方式。
- 混合有符号/无符号运算易产生意外结果，需谨慎。

### 输出
- `%d` 输出整数数值，`%c` 输出对应 ASCII 字符。
- 整数用 `%d`，浮点数用 `%f`，无符号用 `%u`，勿混用。
