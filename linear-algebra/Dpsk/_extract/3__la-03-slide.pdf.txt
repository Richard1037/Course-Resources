线性方程组的两种观点
本节课讲线性方程组，线性方程组仅有未知数和数字相乘，没有高次项，没有交叉项。
（线性方程组在生活中无处不在。例如，在计算机视觉里，图像也可以表示为向量（或者矩
阵，以二维码为例），滤波、边缘检测等对图像的处理可以用矩阵向量乘刻画。一个反问题是，
如果给定了被处理的图像和处理方法，恢复图像（去噪等）往往需要解一个大型线性方程组，见
下图1。）
线性方程组可以用矩阵向量乘法表示，因此也有对应的两种观点。

图2: 矩阵的四种视角。
1. 单位阵I：对于任意的1 ≤i ≤n, A(i, i) = 1, 对于任意的1 ≤i, j ≤n, i̸ = j, A(i, j) = 0。
行观点。列观点。单位阵乘以任何向量得到原向量。
2. 对角阵：对于任意的1 ≤i, j ≤n, i̸ = j, A(i, j) = 0。行观点。列观点。对角阵乘以任何向
量得到原向量的对应坐标伸缩。
3. 下三角阵：对于任意的1 ≤i < j ≤n, A(i, j) = 0。行观点。列观点。回忆前缀和矩阵。下
三角阵乘以任何向量的直观意义。
4. 上三角阵：对于任意的1 ≤j < i ≤n, A(i, j) = 0。行观点。列观点。上三角阵乘以任何向
量的直观意义。
