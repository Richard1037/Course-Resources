## 想补充资料？

**方式一：提 Issue（最省事，不需要会用 Git）**

点 [新建 Issue](https://github.com/Richard1037/Course-Resources/issues/new)，
写清楚要补充哪门课、什么内容就行。

**方式二：提 Pull Request**

会 Git 的话，fork → 添加文件 → 提 PR，我来审核合并。

**方式三：找我要写权限**

如果打算长期一起维护，跟我说一声，把你加为协作者就能直接推文件。

## 目录与命名约定

- 目录一律小写，用连字符分隔：`linear-algebra` 而不是 `liner algebra`
- 课程名用官方英文名
- 文件名统一为 `<课程>-<章节>-<类型>.pdf`，例如 `la-04-slide.pdf`、`am-04-note.pdf`
  （`la` = Linear Algebra，`am` = Advanced Mathematics；类型用 `slide` / `note` / `assignment`）
- 文件名不用中文、不用空格，避免在命令行和 URL 里出问题
