矩阵的加法和数乘
定义1 设A, B 为m × n 矩阵，即A = [aij], B = [bij]，λ ∈R。
• 矩阵加法: A + B = [aij + bij]
• 标量乘法: λA = [λaij]
矩阵的加法与数乘和向量的加法与数乘是类似的。
加法与数乘满足显而易见的性质:
• A + B = B + A (交换律)
• (A + B) + C = A + (B + C) (结合律)
• λ(A + B) = λA + λB (分配律)

矩阵乘法的运算法则
1. C(A + B) = CA + CB (分配律)
2. (A + B)C = AC + BC (分配律)
3. (AB)C = A(BC) (结合律)
证明很容易从矩阵相乘的定义推出。
一个很重要的性质: “AB̸ = BA”，即矩阵乘法不满足交换律。
1. A 与B 的形状可能导致AB 可定义而BA 不可定义。
例如，A 是3 × 2 矩阵, B 是2 × 4 矩阵，AB 是3 × 4 矩阵，但BA 不可定义。
2. 即使AB 与BA 都可以定义，它们也可能不同阶。
例如，A 是3 × 2 矩阵, B 是2 × 3 矩阵，AB 是3 × 3 矩阵，而BA 是2 × 2 矩阵。
